# HMTI UMP First Website

Website resmi pertama Himpunan Mahasiswa Teknologi Informasi (HMTI) Universitas Muhammadiyah Palembang.
Project ini dibuat sebagai bagian dari program kerja Ketua Divisi IT periode 2025–2026.

## 📌 Deskripsi

Website ini bertujuan untuk:

Menjadi media informasi resmi HMTI
Menampilkan profil organisasi
Menyediakan informasi kegiatan dan event
Meningkatkan branding HMTI di dunia digital

## 🛠️ Teknologi

- HTML, CSS, JavaScript
- Bootstrap
